KRACKILICIOUS WEBSITE
=====================

Files:
- index.html   Main website
- style.css    Responsive styling and animations
- script.js    Navigation, scroll reveals, product enquiry and sparkle effects
- assets/      Images cropped from the supplied Krackilicious brochure

HOW TO RUN
1. Extract the ZIP file.
2. Keep index.html, style.css, script.js and the assets folder together.
3. Double-click index.html to open it in a browser.
   For local development, you can also run: python -m http.server 8000
   Then visit http://localhost:8000

CUSTOMISE
- Product names, prices, dimensions and contents are in index.html.
- Colours, typography and layout are in style.css.
- Phone number and email are in index.html (currently brochure details).
- Product images are in assets/.
